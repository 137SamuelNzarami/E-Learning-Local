# Architecture technique

## Backend

Node.js
Express
MySQL

Architecture :

Routes
↓
Middlewares
↓
Controllers
↓
Services
↓
Repositories
↓
Database

## Frontend

React

Architecture :

Pages
↓
Components
↓
Hooks / Context
↓
Services API
↓
Axios / client HTTP
↓
Express API

## Authentification

JWT.

Le token doit être transmis aux routes protégées.

## Communication

Étudiant
↔ Conversation
↔ Formateur

Une conversation peut être créée automatiquement
lorsqu'un étudiant s'inscrit à une formation.

Les conversations administratives restent possibles
selon les permissions prévues.
